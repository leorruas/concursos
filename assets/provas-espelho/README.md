# Acervo de provas-espelho

Esta pasta contém **fontes oficiais em PDF**, não artigos nem uma pasta de projeto da CGU. O catálogo de origem/forma está em `data/corpus-provas-espelho.json` e os hashes efetivos dos arquivos versionados em `data/corpus-pdfs-verificados.json`.

Sincronização: `node scripts/baixar-provas-espelho.mjs`, automatizada pelo workflow `.github/workflows/arquivar-provas-espelho.yml`. Confirmar os arquivos efetivamente presentes no branch antes de afirmar arquivamento. PDFs pendentes, gabaritos preliminares e fontes não validadas permanecem identificados no dossiê, sem simular disponibilidade.

Os arquivos são preservados para estudo, com identificação da fonte e do órgão organizador. Verificar condições de uso e redistribuição antes de republicar ou compartilhar externamente.
